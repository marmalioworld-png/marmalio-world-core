====================================================================
WHAT'S IN THIS PACKAGE
====================================================================

1. Marmalio-Apply_Start-Here-Guide.pdf
   Read this first. Explains the whole system, who it's for, the one
   rule that matters most (nothing in this kit invents your experience),
   and a 30-minute quick-start path if you're short on time.

2. Marmalio-Apply_Complete-Guide.pdf
   The full manual: market-by-market guidance (USA/Canada, UK,
   Australia, and general international), the complete step-by-step
   workflow, LinkedIn/interview/salary-negotiation/career-change
   workflows, limitations and safe use, and three complete fictional
   worked examples.

3. Marmalio-Apply_Prompt-Library.pdf
   All nine prompts in full, one after another, formatted for reading
   start to finish.

4. Marmalio-Apply_Prompt-Library.xlsx
   The same nine prompts in a spreadsheet -- workflow stage, purpose,
   required inputs, the copy-ready prompt text, expected output, truth
   check, refinement step, and market notes, all in separate columns.
   Use this for day-to-day copy-and-paste work; use the PDF for reading.

5. Marmalio-Apply_Resume-Template-1-OneColumn.docx
   One-column, experience-forward resume/CV template. Editable in
   Microsoft Word or Google Docs. Bracketed placeholders are colored
   and italicized -- replace every one of them with your own real
   information before you submit anything.

6. Marmalio-Apply_Resume-Template-2-OneColumn.docx
   One-column, skills-forward resume/CV template -- use this version
   for career changes, recent graduates, or skills-first roles.

7. Marmalio-Apply_Cover-Letter-Template.docx
   Matching cover letter template, same editing rules as the resume
   templates.

8. Marmalio-Apply_Truth-Quality-Safe-Use-Checklist.pdf
   A standalone checklist to run every output through before you send
   anything to an employer. Keep this open while you work.

====================================================================
RECOMMENDED ORDER
====================================================================

1. Read the Start Here Guide.
2. If you're outside the USA, read the Market Distinctions chapter in
   the Complete Guide first.
3. Work through the nine prompts in order, using the Prompt Library
   PDF or spreadsheet -- whichever you prefer to work from.
4. Fill in Resume Template 1 or 2 and the Cover Letter Template with
   your tailored content.
5. Before you send anything to an employer, run it through the Truth,
   Quality and Safe-Use Checklist.

====================================================================
THE ONE RULE THAT MATTERS MOST
====================================================================

Nothing in this system invents your experience, qualifications,
achievements, or results. Every prompt only reorganizes, clarifies,
and tailors information you provide yourself.

====================================================================
WHAT THIS IS NOT
====================================================================

This is not a guarantee of an interview or a job offer. This does not
"beat" applicant tracking systems -- no honest product can claim that.
This is not legal, tax, immigration, or career-counseling advice. Full
detail is in the Truth, Quality and Safe-Use Checklist PDF.
