# Resume Template 2 — One-Column, Skills-Forward

**Design intent for DOCX production:** same single-column, plain, ATS-conscious construction rules as Template 1 (no tables, no text boxes, no graphics, standard heading styles, one plain font). The difference is structural, not visual: this variant leads with a grouped skills/strengths section before the chronological history.

Use this variant for career-changers, recent graduates with thinner work history, or roles where a specific skill set matters more than job titles (see `workflows/career-change-workflow.md`).

**Market note:** same generic-by-design structure as Template 1 (no photo, no date of birth, `[City, State/Country]`, written-out dates) — see `00b-market-conventions.md`.

## Formatting notes for whoever builds the final DOCX/PDF in Canva or Google Docs

- The "Core Strengths" group labels should come from the recurring themes identified in Step 1 (Job Posting Analysis), not from generic category names — this is what makes the same template feel tailored to different roles.
- Keep the same plain, single-column construction rules as Template 1. This template is a different section order, not a different layout system.
- Save/export as both `.docx` (editable) and `.pdf` (submission-ready) — see `packaging-manifest.md`.
