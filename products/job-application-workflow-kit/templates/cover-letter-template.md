# Cover Letter Template

**Design intent for DOCX production:** plain single-column business letter format, same font family as the paired resume for visual consistency, no graphics.

---

```
[FULL NAME]
[City, State/Country] | [Phone] | [Email]

[Date]

[Hiring Manager Name, or "Hiring Team"]
[Company Name]

Dear [Hiring Manager Name / Hiring Team],

[Opening paragraph — names the specific role and one genuine, specific reason for interest. From Prompt 05, point 1.]

[Body paragraph(s) — 2–3 real inventory items connected directly to the role's must-have requirements. From Prompt 05, point 2. One to two paragraphs.]

[Closing paragraph — a clear, low-pressure call to action. From Prompt 05, point 4.]

Sincerely,
[Full Name]
```

## Formatting notes

- 250–350 words total, per Prompt 05's instructions — resist the urge to lengthen it in formatting; length is a content decision made at the prompt step, not a design decision.
- Match the resume's font and header style so the two documents read as one consistent package.
- Export as `.docx` (editable) and `.pdf` (submission-ready) — see `packaging-manifest.md`.
