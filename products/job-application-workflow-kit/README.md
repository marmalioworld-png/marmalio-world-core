## Non-negotiable rules for every file in this product

1. Never use the name "CareerBoost AI" or "ApplyFlow" anywhere.
2. Never call this a "prompt pack" in customer-facing copy — it is Marmalio Apply, a complete guided workflow.
3. Never claim "beat ATS," "ATS-ready," "land interviews," or any guarantee of an interview or job outcome.
4. Honest positioning line, used verbatim wherever a tagline is needed:
   > Build truthful, role-aligned application materials with a clear, ATS-conscious workflow.
5. The system must never invent a candidate's experience, qualifications, achievements, or results. Every prompt that produces candidate-facing content must instruct the AI to use only information the candidate actually supplied, and to flag gaps instead of guessing.
