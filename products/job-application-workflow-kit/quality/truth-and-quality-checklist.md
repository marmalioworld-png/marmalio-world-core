# Truth & Quality Checklist

Run every output from this system through this checklist before sending it to an employer, posting it publicly, or speaking it in an interview. This is not optional — it is the safeguard that makes every other honesty instruction in this system actually work in practice.

## Part 1 — Truth checks (do these first, every time)

- [ ] Every employer name, job title, and date matches your actual records exactly.
- [ ] Every number (percentage, dollar amount, count, duration) traces back to something you explicitly provided — not an estimate the AI produced on its own.
- [ ] No sentence describes an outcome, result, or impact that you did not state actually happened.
- [ ] No skill or tool is listed that you have not actually used.
- [ ] Every `[METRIC NEEDED]`, `[NEEDS INPUT]`, `[NO MATCHING STORY YET]`, or similar flag has been resolved by you — either filled in with a real detail or the surrounding content adjusted so the gap no longer needs filling.
- [ ] If you compare this document to your Experience Inventory (Prompt 02 output) side by side, every factual claim in the final document is present in the inventory.
- [ ] For a career-change narrative specifically: reading it in isolation, it does not create the impression of direct experience you do not have.
- [ ] For a salary negotiation script specifically: every dollar figure was provided by you, not generated.

## Part 2 — ATS-conscious structure checks (resume and cover letter files)

- [ ] Single column throughout — no tables, text boxes, or multi-column layouts used for structural content.
- [ ] No information (contact details, job titles) lives only inside a header or footer.
- [ ] Standard section headings used (Experience, Education, Skills — not creative alternatives like "My Journey").
- [ ] No graphics, icons, or images carrying information that isn't also present as text.
- [ ] Consistent, plain font throughout; no decorative fonts.
- [ ] File saved as both `.docx` and `.pdf`, named clearly (e.g., `FirstName-LastName-Resume.pdf`).

Note: this checklist produces a plain, cleanly-structured document. It cannot and does not guarantee how any specific employer's applicant tracking system will process it — see `limitations-and-safe-use.md`.

## Part 3 — Quality and consistency checks

- [ ] Resume, cover letter, and LinkedIn profile agree on every factual claim (titles, dates, skills).
- [ ] No spelling or grammar errors (read the final version aloud once — this catches errors silent proofreading misses).
- [ ] Tone is consistent within each document (doesn't shift from formal to casual mid-document).
- [ ] Resume fits its intended length (one page under ~8 years of experience, two pages maximum otherwise).
- [ ] Cover letter is 250–350 words.
- [ ] Every bracketed placeholder (`[ROLE TITLE]`, `[COMPANY NAME]`, etc.) has been replaced — search the final file for a literal `[` character before sending anything.

## Part 4 — Final read

- [ ] You have personally read the complete, final document start to finish, out loud, at least once.
- [ ] You would be comfortable being asked, in an interview, to explain and expand on every single claim in this document.

If the answer to that last item is "no" for anything, that item does not belong in the document — remove or revise it before sending.
