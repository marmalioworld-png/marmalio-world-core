# Canva Graphic Briefs

Nothing has been designed yet. This file is the brief the Canva production step will work from — purpose, dimensions, content, and tone for each asset.

## Visual tone (applies to everything)

Clean, professional, calm — not hyped, not neon, not cluttered. This is a career/professional-development product; the design should read as credible and premium, matching the "premium means quality and completeness, not inflated price" positioning. Suggested palette: one confident primary color (e.g., deep navy or forest green) + neutral background (off-white/light gray) + one accent color for callouts. Consistent font pairing across every asset (one serif or strong sans for headers, one clean sans for body).

## 1. Product cover / mockup

- **Purpose:** main product image on the Shopify listing.
- **Dimensions:** 2000×2000px (square, Shopify-standard), plus a 3D-mockup-style version showing a "stack" of the guide + templates.
- **Content:** exact cover title and subtitle from `product-identity.md` ("Marmalio Apply" / "Global Job Application Workflow Kit"), the tagline ("Build truthful, role-aligned application materials with a clear, ATS-conscious workflow."), a visual cue that this is a complete system (e.g., small icons for guide/templates/checklist), NOT a single sheet of paper (avoid implying it's just one document).

## 2. "What's Inside" carousel (5–7 slides)

- **Purpose:** Instagram/LinkedIn carousel and Shopify page.
- **Dimensions:** 1080×1350px per slide.
- **Content:** Slide 1 — title/hook. Slides 2–6 — one system component per slide (9-prompt library / 2 resume templates / cover letter template / 4 workflows / Truth & Quality Checklist), each with a one-line description. Final slide — CTA + price.

## 3. "Before/After" carousel (4–5 slides)

- **Purpose:** demonstrates value without inventing facts — pulls directly from `before-after/before-after-examples.md`.
- **Dimensions:** 1080×1350px per slide.
- **Content:** Slide 1 — hook ("Same facts. Completely different resume bullet."). Slides 2–4 — one before/after pair per slide, using the exact wording from the before-after file (do not alter the examples for the graphic — the honesty of the demonstration matters as much in the visual as in the text). Final slide — CTA.

## 4. "What This Is NOT" myth-busting carousel (4 slides)

- **Purpose:** builds trust through transparency; directly supports the "honest positioning" requirement.
- **Dimensions:** 1080×1350px per slide.
- **Content:** Slide 1 — hook. Slides 2–3 — "❌ [overclaim]" / "✅ [honest claim]" pairs, pulled from `quality/limitations-and-safe-use.md` (e.g., ❌ "Guarantees an interview" / ✅ "Helps you present real experience clearly"). Slide 4 — CTA.

## 5. Social post templates (reusable, 6–8 variants)

- **Purpose:** ongoing week-1 posting beyond the launch carousels — see `social-launch-pack-week1.md`.
- **Dimensions:** 1080×1080px (feed) and 1080×1920px (Stories/Reels cover).
- **Content:** Reusable template frames with swappable headline + body text zones, consistent with the palette/fonts above, for quote-card-style single claims (e.g., pull-quotes from the Truth & Quality Checklist or from the video scripts).

## 6. Video end-card template

- **Purpose:** consistent closing frame for all 6 videos in `shot-list-and-voiceover.md`.
- **Dimensions:** 1080×1920px (vertical).
- **Content:** "Marmalio Apply," confirmed working price (USD 19 launch), "Link in bio" CTA, small trust line ("Built on honesty, not hype" or similar — final wording pending copy approval).

## 7. Video in-video text-card set

- **Purpose:** the on-screen text cards referenced throughout `shot-list-and-voiceover.md` for all 6 scripts.
- **Dimensions:** 1080×1920px per card, built as a reusable Canva template with swappable text so each script's cards share one visual system.
- **Content:** Large, high-contrast text, 1 idea per card, matching the exact on-screen text cues listed in each script.

## 8. Free excerpt cover

- **Purpose:** the downloadable cover for the lead-magnet PDF (`marketing/free-excerpt.md`).
- **Dimensions:** 1000×1294px (standard ebook cover ratio) or matching the main guide's cover style at smaller scale.
- **Content:** "Free Preview: Marmalio Apply," subtitle referencing the Job Posting Analysis prompt inside.

## Production order recommendation

Cover/mockup (1) and end-card (6) first, since every other asset references their visual system. Then the three carousels (2, 3, 4), then social templates (5) and text-card set (7), then the excerpt cover (8) last.

## Localization readiness

Every brief above separates cleanly into two layers: a **visual system** (palette, fonts, layout, icon style, dimensions) and **text content** (headlines, body copy, CTAs). Build each Canva asset as a reusable template with the text in swappable text boxes/layers, not flattened into the design — that's what lets `localization/localization-manifest.md`'s future Polish, German, Spanish, and French versions reuse every visual asset here and only swap the text layer, instead of redesigning from scratch. See `localization/localization-vs-translation.md` for which specific text elements (headlines, claims, examples) need market-aware adaptation rather than a direct swap.
