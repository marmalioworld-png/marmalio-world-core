## ManyChat setup note

Set the comment-trigger keyword to **"WORKFLOW"** across Instagram and TikTok posts in this pack. Comment automation should DM the Shopify product link plus one line ("Here's the system — link below 👇"). Set this up once, before Day 1 posting begins, so every video in the pack benefits from it immediately — this is the actual conversion mechanism behind the content, not the views themselves.

## What is intentionally NOT included in week 1

No paid promotion/ads of any kind. No influencer outreach or paid partnerships. No claims beyond what's approved in `marketing/shopify-product-page.md` and `quality/limitations-and-safe-use.md`. If engagement in week 1 suggests a specific script or format is working best, repeat that format rather than introducing new, unreviewed claims.
