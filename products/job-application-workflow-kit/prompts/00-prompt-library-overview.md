# Prompt Library — Overview

Nine prompts. Not fifty, not a hundred — nine, because that is what the workflow in `01-workflow-overview.md` actually requires. Each one exists to produce a specific, necessary output, not to pad a page count.

| # | Prompt | Produces |
|---|---|---|
| 01 | Job Posting Analysis | Structured breakdown of the target role |
| 02 | Experience Inventory | Your single source of truth |
| 03 | Resume Bullet Rewrite | Clear, honest resume bullets |
| 04 | Resume Tailoring | Role-tailored bullet selection and order |
| 05 | Cover Letter | A grounded, tailored cover letter |
| 06 | LinkedIn Headline & Summary | Updated headline and About section |
| 07 | STAR Interview Preparation | Structured interview answers |
| 08 | Salary Negotiation | Negotiation script and worksheet |
| 09 | Career-Change Narrative | Transferable-skills bridge narrative |

## Format used by every prompt

- **Purpose** — what it does and why.
- **Required Inputs** — what you must have ready.
- **The Prompt** — the exact text to paste into your AI assistant.
- **Expected Output** — what correct output looks like.
- **Truth Check** — the specific question to ask before trusting the output.
- **Refinement Step** — what to paste back if it needs correcting.

## The instruction every prompt shares

Every prompt in this library includes a version of this instruction, because it is the single most important rule in this system:

> Use only the information explicitly provided in this conversation. Do not invent, assume, exaggerate, or infer any employer, title, date, responsibility, skill, metric, or outcome that was not stated. If something is missing or unclear, output `[NEEDS INPUT: ...]` describing exactly what you need, instead of guessing.

If you ever see an AI assistant produce output that ignores this instruction, stop, correct it using the Refinement Step, and re-run the Truth Check before continuing.
